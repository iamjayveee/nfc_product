# Working in NFC Product

Read CONTEXT.md, then follow the route relevant to the current task.

## Working agreement

- Follow the project's existing rules and the agreed scope of work.
- Read only the records needed for the task.
- Inspect current files and Git status before editing, when Git is available.
- Preserve unrelated work and keep each authoritative fact at one home.
- When an important working boundary is missing, show a concrete proposal
  and explain its benefit and cost before applying it.
- Proceed within existing authorization; do not repeatedly reopen settled decisions.
- Report actual changes, checks, and limitations. Passing checks do not
  supply an approval the project requires separately.
- Save continuation information through the project's declared memory procedure.

## Project rules

- Inspect the repository before choosing tools or adding dependencies.
- Do not commit or push unless explicitly requested.
- `IDEA-SCOPE.md` changes only as its §14 allows.
- `scope/` checkpoints are history: add revision-log rows only.
